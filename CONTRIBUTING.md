# Руководство по вкладу в проект

## Как помочь

### Сообщение об ошибках
1. Проверьте, что ошибка не была уже сообщена
2. Используйте шаблон Issue
3. Приложите логи аддона

### Pull Requests
1. Форкните репозиторий
2. Создайте ветку: `git checkout -b feature/amazing`
3. Внесите изменения
4. Протестируйте
5. Отправьте PR

## Кодекс поведения
Мы обязуемся сделать участие в проекте свободным от домогательств для всех.
