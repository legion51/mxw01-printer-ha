# MXW01 Printer Terminal for Home Assistant

[![HACS](https://img.shields.io/badge/HACS-Integration-orange.svg)](https://github.com/hacs/integration)
[![GitHub Release](https://img.shields.io/github/release/legion51/mxw01-printer.svg)](https://github.com/legion51/mxw01-printer/releases)
[![License](https://img.shields.io/github/license/legion51/mxw01-printer.svg)](LICENSE)

Веб-терминал для печати на термопринтерах MXW01, Lefuxin, ESC/POS через Web Bluetooth в Home Assistant.

## Быстрая установка

1. Добавьте репозиторий в HACS
2. Установите интеграцию
3. Установите аддон через Supervisor

## Возможности

- 🖨️ Поддержка MXW01, Lefuxin, ESC/POS
- 📝 Markdown редактор
- 📱 QR-коды
- 🖼️ Изображения
- 🔄 Drag & Drop
- 🌐 Web Bluetooth
- 🌍 RU/EN интерфейс
